IMPLEMENTED INTEGRATION
English speech-to-text uses NCAIR1/NigerianAccentedEnglish, pinned to revision 3c52c6e6c9ec508014a7b9db6a42b503b8930dff. The corrected and confirmed question can use NCAIR1/N-ATLaS, pinned to revision e294476928aca9030e924ca27bb8e085e8581273, for constrained relevance checking of reviewed payment-safety content. Both run on the team's authenticated SecretVM host. Model calls and secrets remain server-side. The text model uses a documented Q4_K_M CPU conversion of the official weights; quantization is not fine-tuning.

CAPABILITY AND VALIDATION BOUNDARIES
These are genuine engineering/owner checks, not independent participant-validation results. On 3 October, the owner reports that 25 testers have tried the app and feedback is being collected. Their completed voice interactions, consent and outcomes have not yet been reconciled; no success rate or minimum-50 claim is made. Only English is currently enabled. Official N-ATLaS API requests and fine-tuning are not demonstrated. Organiser confirmation that self-hosting official ASR weights qualifies as the required ASR service is pending. App readout uses browser/device speech; the separately labelled demo narrator uses Microsoft Nigerian-English TTS, not N-ATLaS speech generation.

No API keys, tokens, participant identities, raw audio, private bank records or credentials are included in this note. No ONDI application has been submitted.
